# Дипломный проект: Управление жизненным циклом рабочего места программиста

Данный репозиторий содержит выпускную квалификационную работу (дипломный проект), состоящую из клиентской (Frontend) и серверной (Backend) частей.

## 📂 Структура проекта

```text
Diplom/
├── backend/          # Серверное приложение (FastAPI)
│   ├── app/          # Основной код приложения (модели, схемы, роуты)
│   ├── tests/        # Модульные и интеграционные тесты (pytest)
│   └── requirements.txt  # Зависимости Python
├── frontend/         # Клиентское приложение (React + TypeScript + Vite)
│   ├── src/          # Исходный код интерфейса
│   ├── public/       # Статические ресурсы
│   └── package.json  # Зависимости npm
└── .gitignore        # Глобальный файл игнорирования Git
```

---

## 🛠️ Технологический стек

### **Backend (Сервер)**
* **Фреймворк:** [FastAPI](https://fastapi.tiangolo.com/) (высокопроизводительный асинхронный веб-фреймворк на Python 3)
* **База данных:** SQLite (для локального хранения данных)
* **ORM:** [SQLAlchemy](https://www.sqlalchemy.org/)
* **Работа с графами знаний:** [RDFLib](https://github.com/RDFLib/rdflib) (семантические сети, онтологии)
* **Тестирование:** [Pytest](https://docs.pytest.org/)

### **Frontend (Клиент)**
* **Фреймворк/Библиотека:** [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
* **Инструмент сборки:** [Vite](https://vitejs.dev/)
* **Стилизация:** Современный CSS (Premium UI/UX)

## 🚀 Быстрый запуск

### 1. Сервер (Backend)
Перейдите в папку `backend`, настройте виртуальное окружение и запустите сервер:

```bash
cd backend

# Создание виртуального окружения
python -m venv .venv

# Активация виртуального окружения:
# На Windows (PowerShell):
.venv\Scripts\Activate.ps1
# На macOS/Linux:
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
uvicorn app.main:app --reload
```
После запуска документация API (Swagger UI) будет доступна по адресу: `http://127.0.0.1:8000/docs`
База данных `workplace.db` будет создана и наполнена начальными данными автоматически при первом запуске!

### 2. Клиент (Frontend)
Перейдите в папку `frontend`, установите зависимости и запустите dev-сервер:

```bash
cd ../frontend

# Установка пакетов
npm install

# Запуск в режиме разработки
npm run dev
```
Интерфейс откроется в браузере по адресу: `http://localhost:5173/`

## 🧪 Запуск тестов
Чтобы запустить тесты бэкенда, перейдите в папку `backend` с активированным виртуальным окружением и выполните:
```bash
pytest
```
